# GenomeSpy UI Components

This repository owns the Lit components, styles, and browser utilities shipped
as `@genome-spy/ui-components`. GenomeSpy App, Playground, and the focused apps
own their themes, data, and workflows.

- For browser UI and platform API choices, use
  [Modern Web Guidance](.agents/skills/modern-web-guidance/SKILL.md) alongside
  the component development skill.
- For component changes, use
  [develop-ui-components](.agents/skills/develop-ui-components/SKILL.md).
- For API documentation or Storybook changes, use
  [document-ui-components](.agents/skills/document-ui-components/SKILL.md).
- For npm package and release work, use
  [prepare-ui-components-release](.agents/skills/prepare-ui-components-release/SKILL.md).
- For preparing, reviewing, or writing a pull request, use
  [prepare-ui-components-pr](.agents/skills/prepare-ui-components-pr/SKILL.md).

Keep source in JavaScript with JSDoc. Read the
[development commands](README.md#development) and use Conventional Commits.
