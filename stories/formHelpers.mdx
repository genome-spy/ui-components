# Form helpers

Use `FormController` and `formField` to bind native controls to reactive Lit
properties and show inline validation errors. The bookmark form below works
inline and in a dialog.

Try **Save** with an empty title. The form shows the error and focuses Title.
Enter a title and press **Enter** or choose **Save** to see the submitted
values. Open **Show code** for the complete form component.

## Write a form

Prefer native HTML form controls such as `<input>`, `<select>`, `<textarea>`,
and `<button>` whenever they meet the form's needs.

1. Import `formStyles` from `@genome-spy/ui-components/styles` into the Lit
   component that renders the controls. Wrap each label, control, and its
   feedback in `.gs-form-group`. Use `<small>` for hints and link each label to
   its control with `for` and `id`.
2. Create a `FormController` in the constructor and call `defineField()` once
   per field. Use `valueKey` to name a reactive string property. A validator
   returns an error message or `null`. Set `affects` on a field when another
   field needs revalidation after it changes.
3. Apply `formField(form, name)` to each input, textarea, or select. It binds
   `.value`, sets `aria-invalid`, and validates on blur and while editing a
   field with an error. Render `form.feedback(name)` below the control and
   reference the error with `aria-describedby` while it is visible.
4. Handle the form's `submit` event. If `validateAll()` returns `true`, show the
   errors and focus the first invalid field. Otherwise, pass the values to the
   caller. `hasErrors()` can check validity without showing feedback. This form
   uses `novalidate` so its handler can show the controller's messages,
   including the error for whitespace-only titles.

For native controls in light DOM, import `@genome-spy/ui-components/form.css`
and add `.gs-form` to the form. See **Theming → Scoped palettes → Native Form
Controls**.

## Use the form in a dialog

**Components → Dialog → Validated Form** renders the same bookmark form inside
`BaseDialog`. The form supplies the fields and validation. The dialog supplies
the title and footer, sends Save through `requestSubmit()`, and closes after a
successful `bookmark-save` event. A nested Lit form imports `formStyles` for its
own shadow root.

## Validate a dialog step

`DialogWizardController` takes a Lit host with a reactive numeric `_page`
initialized to `0`, plus an array of pages with `render()` functions. Render
`wizard.currentPage` and build the footer using `wizard.isFirstPage` and
`wizard.isLastPage`.

Use `wizard.advance(1)` or `wizard.advance(-1)` to move between pages. A page's
`onAdvance` can return `false` to block forward navigation. For a validated
step, set `onAdvance: () => !this.form.validateAll()`. The dialog owns the
buttons and decides when to finish.

Try **Next** with an empty name to see the validation gate. Enter a name to
continue to the review step.
